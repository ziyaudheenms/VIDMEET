# 🚀 VIDMEET: The Complete Video Conference Application

VIDMEET is a modern, full-stack video conferencing platform built for seamless instant and scheduled meetings. With robust features, secure authentication, and a professional UI, VIDMEET showcases advanced full-stack development using Next.js and Stream Video SDK.

---

## ✨ Features

- **⚡️ Instant Video Calls:** Start or join meetings instantly.
- **🗓️ Meeting Scheduling:** Schedule meetings for future dates (time selection coming soon).
- **📂 Call Management:** View upcoming and past meetings in a unified dashboard.
- **📹 Meeting Recording:** Record meetings and save them for later reference.
- **🔒 Personal Meeting Room:** Create and customize your own permanent meeting space.
- **🖥️ Rich UI/UX:** Enjoy a polished, intuitive interface with all essential controls.
